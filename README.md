# kedovo-media

Kedovo's permanent archive of finished social videos, and the public link
Metricool (the scheduler) fetches each video from when a post is scheduled.

- Written only by the kedovo-marketing pipeline (`01Akshaj-Maker/kedovo-marketing`, `tools/media_host.py`).
- Files live under `reels/<week>/<slug>.mp4`, each with its cover `<slug>.cover.jpg`.
  The tracker in kedovo-marketing records which post uses which file.
- Nothing is removed: this is the archive.
- Everything here is public: finished, approved content only.
