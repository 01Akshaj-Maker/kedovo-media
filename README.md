# kedovo-media

Public hosting for Kedovo's finished social videos. Metricool (the scheduler)
fetches each video from its link here when a post is scheduled.

- Written only by the kedovo-marketing pipeline (`01Akshaj-Maker/kedovo-marketing`).
- Files live under `reels/<slug>.mp4`. The tracker in kedovo-marketing records which post uses which file.
- Everything here is meant to be public: finished, approved content only.
